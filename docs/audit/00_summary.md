## 1. 記録・プレー結果が LR2 とずれるもの（優先して直す）

2026-10-19：1〜6 は直した（3 は配置のオプションだけ。5 鍵のスキン・op161・鍵盤数の絞り込みはまだ）。6 はゴースト（LR2 の文字列の形式。LR2 のゴーストも引き継ぐ）・ターゲット（IR 以外）・リプレイ（BMjoy の形式。曲中のハイスピの変更とコースのステージは残さない）・乱数の種・op_best。

1. **SCATTER・CONVERGE・皿の自動演奏・CONSTANT の記録**（01・04）。LR2 は EASY 止まりのランプ（FC も EASY）と回数・オプション履歴だけを残し、スコアは残さない。BMjoy は CONVERGE が EASY 止まりにならず、SCATTER は BPM が一定なら FC を残し、SCATTER と皿の自動演奏はスコアまで残す。CONSTANT は逆にランプも回数も残さない。コースのステージでも同じずれ。
2. **閉店したときの BP**（01・04）。LR2 は遊ばなかった残りのノーツを必ず BP に足す。BMjoy は途中でやめたときだけ足すので、閉店したプレーの BP が少なく残る。リザルトのグラフの残りも 0 で埋めていない。
3. **5 鍵の譜面**（01・02）。LR2 は 18・19 チャンネルの無い譜面を 5 鍵として、RANDOM などを 1〜5 の中で入れ替える。BMjoy は 1〜7 で入れ替えるので、6・7 にノーツが出る。選曲の鍵盤数の絞り込みにも要る。
4. **#RANDOM 0（値なし）で乱数を 1 つ使わない**（02）。LR2 は使うので、その後の #RANDOM とレーンの入れ替えが全部ずれる。
5. **コースの判定の横のコンボ**（01）。LR2 はコース通しのコンボ、BMjoy は曲ごと。
6. **リプレイ、ゴーストのデータ（判定の並び）、乱数の種、op_best を保存していない**（04）。

## 2. 遊ぶときの動きが違うもの

- 選曲画面に戻ったとき、LR2 は画面を始め直す（入場の演出、#STARTINPUT まで入力を受けない）。BMjoy は始め直さない（03）。
- 鍵盤数の絞り込みで 0 件になっても次へ進まない（14KEY を選ぶと全部消える）（03）。
- START を押している間も、キーボードの Enter・→・← が効く（LR2 では止まり、←→ は TARGET の変更）（03）。→ 直した。
- 決定画面：#STARTINPUT の前から戻れる、戻っても決定音が止まらない、飛ばしても #SCENETIME でプレーへ進む、BANNER と BACKBMP を読まない、#SCENETIME の無いスキンで先へ進まない（03・04）。→ 直した。
- 全部のノーツが終わったあと START か SELECT だけで曲を終える操作が無い。閉店の演出中も ESC が効く（01）。→ 直した（右クリックで曲を終える操作と、その設定も足した）。
- 曲の始まりで START・SELECT を離すのを待たない（01）。→ 直した（数字キーも待つ）。
- 譜面：最初に足す空の小節の長さ（#00002 があるとき）、#BPM の無い譜面を読まない、曲名と副題を括弧で分けない、#GENRE からの難易度の推定が無い、キー音の探し方（.flac・.mp3、親フォルダでの拡張子の差し替え、2 段以上下のフォルダ）、FLAC を読めない（02）。→ 直した（キー音・BGA の探し方も play_session.cpp から使うようにした）。
- 小さいもの（BAD から LN へ続くときの扱いと、曲バーのクリックの動き以外は直した。この 2 つは LR2 の癖に近いので、まねずに残す）：BAD から LN へ続くときの扱い、TOTAL の既定式のノーツ数（RANDOM で重なりが消えたあとの数）、LN を離したときのボム（タイマー 50）、地雷での判定の再表示（タイマー 46）（01）。UTF-8 の BOM（02。直した）。ボタン 15/16 をフォルダの上で押すとフォルダが開く、ソートと絞り込みが起動し直すと戻る、曲バーのクリックの動き、検索と難易度表で同じ譜面が 2 回出ることがある（03）。
- スキン：#FLIPRESULT / #DISABLEFLIP を読み込みの順に処理していない（LR2 標準リザルトの RESULT SIDE が効かない）、改行が LF だけのスキンで #IF の入れ子が崩れる、#CUSTOMFILE を番号で保存している（ファイルが増減すると選択がずれる）（04）。→ 直した（あわせて #CUSTOMFILE の候補の集め方・既定・RANDOM、#CUSTOMOPTION の 900〜999 も LR2 に合わせた）。
- 音：コースクリア・失敗の音が 1 回しか鳴らない（LR2 は繰り返す）、サウンドセットで選んだ BGM のフォルダが反映されない（04）。→ 直した。
- 設定アプリ：levelbar_5 / levelbar_9 を本体が読まない、「右クリックで曲を終了させない」などの表示が LR2 の既定と違う（04）。→ 直した（levelbar_5 は 5 鍵の譜面で使う。levelbar_9 は 9 ボタンを扱わないので灰色）。

## 3. BMjoy に無いもの（大きい順の目安）

2026-10-19 の進み具合：
- 入れた：MASTER/KEY/BGM の音量・EQ・エフェクタ・ピッチ（遅くして遊ぶと回数だけを残す）とリザルトのフェードアウト、ターゲット（IR 以外）と 2P 側のゴースト、スコアグラフ・ゴーストの位置・BGA の大きさの設定、NEW SONG と新曲の色、お気に入り／IGNORE、カスタムフォルダ（.lr2folder。#COMMAND は LR2 と同じ形の表で動かす。難易度表の管理ツールのものは URL の難易度表と重なるので読まない）、folderinfo.txt の #TITLE、フォルダランプ、パネル 1 の TARGET と鍵盤数、タグエディター、SEARCH FAILED、F8、スクリーンショット、LR2 のキーコンフィグ用スキンの画面（START/SELECT の割り当て、その場での保存）、スキンの位置の調整、右クリック、マウスの 2 度押し、スキンの動画、#FONT の縁取り、リプレイ、キーコンフィグとスキンセレクトへ移る前のフェードアウト。
- 別に作っている途中：MIDI、パッドを台ごとに区別すること。
- やらない（理由は報告に書く）：テーマの一括切り替え（種類 11。書き方が分からず、手元に例も無い）、G-BATTLE（2P 側のレーンを描く仕組みが要る。BMjoy は SP だけ）。

- **音量の処理**：MASTER / KEY / BGM の音量、EQ、ピッチのスライダー、リザルトを抜けるときの音のフェードアウト（04）。
- **ターゲットと 2P 側のゴースト**：自己ベスト・AAA・AA・A・％ などのターゲット、スコアグラフ・ゴーストの位置・BGA の大きさの設定（01）。
- **選曲**：NEW SONG と新曲の色（DB に追加日時が無い）、お気に入り／IGNORE、カスタムフォルダ（.lr2folder）と folderinfo.txt、フォルダランプ、パネル 1 の TARGET と鍵盤数の切り替え、タグエディター、検索の細かい機能、今のフォルダだけの読み直し（F8）とフォルダの監視（03）。
- **スクリーンショット**（F6）（04）。
- **キーコンフィグ**：LR2 の KeyConfig スキンが使えない、ウィザードで START/SELECT を割り当てられない、Esc で抜けると保存されない（04）。
- **プレー中**：スキンの位置の調整（数字キー＋矢印）、右クリックで曲を終える、マウスのダブルクリックでカバーの出し入れ、G-BATTLE（01）。
- **スキン**：動画の画像、#FONT の縁取り、スキン全体の位置・大きさの調整、テーマの一括切り替え（04）。
- **入力**：MIDI、パッドを台ごとに区別すること（04）。

## 4. 決めてもらいたいこと

1. **選曲の ESC と F キー**：LR2 は ESC でどの階層からでも終了し、F キーの割り当ても違う（F1 説明、F2 マニアック、F5 IR のページ、F6 スクリーンショット、F7 FPS、F8 今のフォルダの読み直し）。LR2 に合わせるか、BMjoy の違いとして仕様書に書くか。
2. **LR2 に無い操作**（リザルトの F5 で即リトライ、プレー中の F4 など）を残すか。
3. **選曲画面に出す数**（ノーツ数・BPM の幅）：LR2 は #IF 1 の分岐で数え、見えないノーツも含め、BPM はヘッダーの定義から読む。BMjoy の方が正確だが、LR2 と見える数が違う。
4. **定義されていない STOP**：LR2 は時刻がわずかに戻る不具合がある。まねるか。
5. **フルスクリーンの既定**（LR2 は排他フルスクリーン）と、SD のスキンのウインドウを 200% にしていること。
6. **LR2 からの引き継ぎを広げるか**：スキンのカスタマイズ（SkinCustomize）、お気に入り、カスタムフォルダなど。

### 決まったこと（2026-10-19）

1. ESC と F キー：LR2 に合わせる。済み（2026-10-19）：ESC はどの階層からでも終了、F1 は押している間の説明、F3+矢印で難易度とレベルの書き換え、F6 のスクリーンショット（どの画面でも。`screenshot/BMjoy 日時.png`）、F7 の FPS、F8 は今の曲フォルダだけ読み直し。F2（マニアックオプション）と F5（IR）は中身が無いので何もしない。BMjoy で付けていた F1 キーコンフィグ・F2 オート・F6 レーンカバーと F5 の全部の読み直しは外した（スキンのボタン 13・15/16・46 は使える）。F キーの割り当ては、あとでキーコンフィグで変えられるようにしたい（ユーザーの希望）。
2. LR2 に無い操作：リザルトの F5 とプレー中の F4 は残す。
3. 選曲画面に出す数：BMjoy の数え方のまま（LR2 の数え方はまねない）。
4. 定義されていない STOP：LR2 の不具合はまねない。
5. 画面の既定：SD スキンの 2 倍はそのまま。起動はウインドウで始め、そのあとは最後に使った状態（F4 で切り替えたら保存する）。
6. LR2 からの引き継ぎ：お気に入りなどには広げない。スキンのカスタマイズ（LR2files/SkinCustomize の #CUSTOMOPTION・#CUSTOMFILE の選択）は引き継ぐ。位置や大きさの調整（shift・rate・size など）は BMjoy に無いので読まない。
