# 監査 03：選曲画面・曲データベース・決定画面（LR2 との突き合わせ）

対象: BMjoy の選曲（`src/app/select_scene.cpp` ほか）・曲 DB・決定画面を、OpenLR2（LR2 の書き起こし）と突き合わせた結果。**挙動だけ**を書く（OpenLR2 のコードは写さない）。

- 既存の仕様書 `docs/lr2_select_spec.md`（以下 SEL）、`docs/lr2_songlist_spec.md`（以下 LIST）、`docs/lr2_course_spec.md`（以下 CRS）、`docs/lr2_skin_ids.md` にすでに書いてある LR2 側の仕様は繰り返さず、**BMjoy が今それに合っているか**と、そこに書かれていない残りの差を中心に書く。
- 出典の略号
  - OpenLR2（`参考に/OpenLR2-main/LR2/`）: `SS`=Scene02_Songselect.cpp、`SM`=LR2_songmanage.cpp、`SO`=LR2_skinobject.cpp、`MAIN`=Main.cpp、`GL`=LR2_gameloop.cpp、`DC`=Scene03_Decide.cpp、`ST`=LR2_statplay.cpp
  - BMjoy: `sel`=src/app/select_scene.cpp、`ctx`=src/app/select_context.cpp、`dec`=src/app/decide_scene.cpp、`db`=src/db/song_db.cpp、`imp`=src/app/lr2_import.cpp、`crs`=src/app/course.cpp
- 記号: `[?]` 不確か（書き起こしの誤りの可能性・推論）、`[EXT]` OpenLR2 だけの拡張（原典 LR2 に無い）。
- 判定: **同じ／違う／BMjoyに無い／意図した違い／LR2に無い**。「意図した違い」は、難易度表をルートに置く・ソートと鍵盤数の項目は beatoraja・コースは難易度表から・LR2 の取り込み・プレビュー・ハイスピは BMjoy 独自（memory: hispeed-modern-not-lr2）など、ユーザーが決めたもの。

## BMjoy に無いもの（優先度の目安）

**高（普段の選曲で困る・LR2 から来た人がすぐ気づく）**
1. **NEW SONG と新曲のタイトル色**: 追加日時の列が無いので両方出せない。描画側（`is_new`）は準備済みなので、DB に追加日時を持てばすぐ出せる。
2. **お気に入り / IGNORE（ボタン 90）**: 列もボタンも無い。LR2 の取り込みでも落ちる。
3. **カスタムフォルダ（.lr2folder）と folderinfo.txt**: 自作フォルダ・RANDOM・TOP10 などが全部使えない。LR2 の取り込みでも捨てている。BMjoy の仮想フォルダ（仕様書 9 章）として作るなら、`#COMMAND` の SQL をどこまで受けるか要判断。
4. **フォルダランプ**: 仕様書 v0.1 8 章に設計があるが未実装。難易度表のフォルダで特に欲しい。
5. **パネル 1 の TARGET（SELECT・鍵盤 8・←→）と 鍵盤 1 の鍵盤数切り替え**: TARGET の仕組み自体が無い（文字列 1 が「NO TARGET」固定）。

**中**
6. タグエディター（パネル 4、文字列 20..29、ボタン 18）と F3 によるレベル・難易度の書き換え。
7. 検索の `/` コマンド（少なくとも /hash /path）、検索対象に path・tag、`a-b` の BPM 範囲。

## 違っているもの（直すべき候補）

1. **選曲に戻ってきたときにシーンを始め直していない**（sel:830-858）。LR2 は戻るたびに timer 0 から始まり、#STARTINPUT まで入力を受けず、入場アニメも出る。BMjoy は最初に入ったときの timer 0 のままなので、スキンのアニメが出ず、戻った直後の誤入力も防げない。

3. **パネル 1（START を押している間）でもキーボードの Enter・→・← が効く**（sel:1261-1282）。LR2 は START を押している間はリスト操作を全部止め、←→ は TARGET の変更になる。START を押しながら Enter で決定してしまう。
