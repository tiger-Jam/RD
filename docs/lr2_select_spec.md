# LR2 選曲画面 × LR2スキン 挙動仕様書（BMjoy 実装用）

対象: LR2 (beta3 系) の選曲画面 (`procSelecter == 2`) が LR2 select スキンをどう駆動するか。
目的: BMjoy で LR2 互換の選曲画面を **仕様から** 実装するための資料。OpenLR2 のコードは複写していない（振る舞いを文章・表・短い擬似式で記述）。

## 0. 凡例・出典・前提

- 出典
  - OpenLR2 (LR2 の書き起こし): `参考に/OpenLR2-main/LR2/` の `Scene02_Songselect.cpp`, `LR2_skinload.cpp`, `LR2_skindraw.cpp`, `LR2_skinobject.cpp`, `LR2_gameloop.cpp`, `Main.cpp`, `structure.h`, `En_value.cpp`, `En_timer.cpp`, `En_input.cpp`, `LR2_statplay.cpp`, `LR2_songmanage.cpp`
  - 実スキン: `参考に/LR2beta3 2/LR2files/Theme/WMIX_HD/select/select.csv` (CP932)
  - LR2 標準スキン: `参考に/LR2beta3 2/LR2files/Theme/LR2/Select/select.csv`
  - マニュアル: `参考に/LR2beta3 2/help/3.html`（曲セレクト）, `4.html`（コントロールパネル）, `history.txt`
  - `参考に/OpenLR2-main/new_command(skin).md`（OpenLR2 拡張コマンド一覧）
- 記号
  - **[W]** = WMIX_HD の select.csv で実際に使われている（実装優先）
  - **[-]** = WMIX では未使用
  - **[EXT]** = OpenLR2 拡張（オリジナル LR2 には無い）。BMjoy では原則入れない／入れるなら別扱い
  - **[?]** = 不確か。OpenLR2 の書き起こしの癖・バグの可能性、または原典で確認できていない
- 時間単位はすべて ms。座標はスキン座標（WMIX_HD は 1280x720 想定）。
- 「押した」= 入力状態 1（押下エッジ）、「押している」= 2（ホールド）、「離した」= 3（リリースエッジ）、0 = 無入力。マウスボタンも同じ 0/1/2/3。

## 1. 共通基盤（選曲専用コマンドが依存する部分）

### 1.1 CSV 解析
- 1 行をカンマで最大 30 フィールドに分割。各フィールドは文字列と整数値（`atol`）の両方を持つ。空欄は 0。
- 値が `!` で始まる場合は **負数**として読む（`!3` → -3）。op 指定の否定に使われる。WMIX でも `!3`, `!4` が登場する。
- 以下「csv[n]」は 0 始まり（csv[0] がコマンド名）。

### 1.2 SRC の共通フィールド（`#SRC_IMAGE` 型。選曲専用の画像系 SRC もすべてこれ）
| csv | 意味 | 備考 |
|---|---|---|
| 1 | index（コマンドによっては無視） | |
| 2 | gr（`#IMAGE` の登録順番号, 0..99）／特殊番号 | 100=STAGEFILE, 101=BACKBMP, 102=BANNER, 110=黒, 111=白 |
| 3,4 | x, y | 1 未満は 0 |
| 5,6 | w, h | 負なら画像全体サイズ |
| 7,8 | div_x, div_y | 1 未満は 1。フレーム数 = div_x*div_y |
| 9 | cycle | アニメ 1 周の ms。0 以下ならアニメ無し（フレーム 0） |
| 10 | timer | SRC アニメの基準タイマー |
| 11..15 | op1..op5 | コマンドごとに意味が違う（後述） |

- フレーム並びは「x 方向が先」: frame = i + div_x*j（i: 列, j: 行）。
- 現在フレーム = `(経過ms % cycle) * フレーム数 / cycle`（経過<0 なら 0）。
- SRC timer と DST timer が同じ場合は「SRC 経過 − DST 先頭キーフレーム time」でフレームを計算する（通常オブジェクト描画時）。曲バー本体だけは DST 先頭補正なしで SRC timer の経過を直接使う。

### 1.3 DST の共通フィールド
| csv | 意味 |
|---|---|
| 1 | index |
| 2 | time（キーフレーム時刻） |
| 3,4,5,6 | x, y, w, h（テキスト系では h=フォントサイズ） |
| 7 | acc（補間）0=線形, 1=加速(3乗 ease-in), 2=減速(3乗 ease-out), 3=補間せず前のキーを保持 |
| 8 | a |
| 9,10,11 | r, g, b |
| 12 | blend 0=なし,1=α,2=加算,3=減算,4=乗算,5=減算2,9=反転(dest),10=反転(src),11=乗算α、その他→α |
| 13 | filter |
| 14 | angle |
| 15 | center |
| 16 | loop（**最初の行のみ有効**） |
| 17 | timer（**最初の行のみ有効**） |
| 18,19,20 | op1, op2, op3（描画条件。**最初の行のみ有効**） |
| 21 | op4（**最初の行のみ**。画像のスクラッチ回転用） |
| 22 | op5（最初の行のみ） |

- 同じオブジェクト（同 index）への DST 行は順にキーフレームとして追加される。
- 時刻 t（= DST timer の経過）での評価:
  - timer 未起動（-1）または t < 先頭 time → 非表示。
  - loop < 0 かつ t > 最終 time → 非表示。
  - キーフレームが 1 つ、または loop == 最終 time → 最終状態を保持。
  - loop < 最終 time → t > 最終 time では `(t − loop) % (最終 − loop) + loop` でループ。
  - loop > 最終 time → 常に t=0 として評価（[?] 書き起こしどおり）。
- op1..op3 は「すべて真なら描画」。op は §6.2 の GetOptionFlag。負数は否定。0 は常に真。
- **描画順** = DST 行のスキン内での出現順（行番号＝sortID、`#INCLUDE` 先も通し番号）。全オブジェクトを sortID 昇順で描く。曲バー本体だけは 2 行の sortID を補間した値になる（§3.3）。

### 1.4 フレーム内の処理順（選曲画面）
1. 入力取得 → readme 表示中ならスクロール/閉じ判定 → 鍵盤タイマー(100-139)更新 → **スライダー処理** → **ボタン処理**
2. 選曲ロジック（リスト入力・決定・パネル・曲バー描画登録）
3. 画像 → ボタン → スライダー → 数値 → ONMOUSE → テキスト → BARGRAPH → マウスカーソル → readme の順で描画登録
4. sortID でソートして描画

ボタンがクリックされたフレームは選曲ロジックのリスト入力が丸ごと無視される（§4.1 の前提条件）。

## 2. 選曲専用スキンコマンド

### 2.1 一覧と WMIX 使用状況
| コマンド | index 範囲 | WMIX | 概要 |
|---|---|---|---|
| `#SRC_BAR_BODY` | 0..9（※） | [W] 10 | 曲バー画像。index = バー種別 |
| `#DST_BAR_BODY_OFF` | 0..29 | [W] 0..20 | 非選択行の配置 |
| `#DST_BAR_BODY_ON` | 0..29 | [W] 0..20 | 選択行の配置 |
| `#BAR_CENTER` | 0..29 | [W] 10 | カーソル行 |
| `#BAR_AVAILABLE` | from,to | [W] 10,10 | クリックで直接選べる行範囲 |
| `#SRC_BAR_TITLE`/`#DST_BAR_TITLE` | 0..4（実使用 0,1） | [W] 0,1 | 曲名テキスト |
| `#SRC_BAR_FLASH`/`#DST_BAR_FLASH` | なし | [W] | 選択行のフラッシュ |
| `#SRC_BAR_LEVEL`/`#DST_BAR_LEVEL` | 0..10（実使用 0..6） | [W] 0..6 | バー上のレベル数字 |
| `#SRC_BAR_LAMP`/`#DST_BAR_LAMP` | 0..9（実使用 0..5） | [W] 1..5 | クリアランプ |
| `#SRC_BAR_MY_LAMP`/`#DST_BAR_MY_LAMP` | 0..9 | [W] 1..5 | ライバル比較時の自分ランプ |
| `#SRC_BAR_RIVAL_LAMP`/`#DST_BAR_RIVAL_LAMP` | 0..9 | [W] 1..5 | ライバル比較時のライバルランプ |
| `#SRC_BAR_RIVAL`/`#DST_BAR_RIVAL` | 0..9（実使用 0..3） | [W] 0..2 | 勝敗マーク |
| `#SRC_BAR_RANK`/`#DST_BAR_RANK` | 0..9 | [-] | IR ランキング表示中のランク |

| `#RELOADBANNER` | フラグ | [W]（#IF 938 内） | 選曲中にバナーを読む |
| `#DST_BAR_STAGEFILE`, `#SRC/DST_BAR_STAR` | | [-] | 通常の選曲画面では**使われない**（OpenLR2 ではイベントモード選曲専用） |

※ `#SRC_BAR_BODY` は読み込み時の範囲チェックが 0..29 だが、格納先は 10 要素しかなく、描画で参照されるのも 0..9（バー種別）のみ。BMjoy は 0..9 として扱い、10 以上は無視（警告）でよい。`#SRC_BAR_LEVEL` も範囲チェック 0..10 に対して格納 10 要素（index 10 は事実上無効）。

### 2.2 `#SRC_BAR_BODY,index,gr,x,y,w,h,div_x,div_y,cycle,timer`
- 共通 SRC（§1.2）。op は未使用。
- **index = 曲リスト要素の種別 (folderType)**:

| index | 種別（LR2 標準スキン/WMIX のコメントと一致） |
|---|---|
| 0 | 曲 |
| 1 | フォルダ |
| 2 | カスタムフォルダ |
| 3 | 新曲フォルダ |
| 4 | ライバルフォルダ |
| 5 | 曲（ライバルモード用 = ライバルフォルダ内の曲） |
| 6 | コースフォルダ |
| 7 | コース作成（NEW COURSE） |
| 8 | コース |
| 9 | ランダムコース |

- 画像アニメは SRC timer の経過で回す（DST 先頭補正なし）。

### 2.3 `#DST_BAR_BODY_OFF,index,...` / `#DST_BAR_BODY_ON,index,...`
- index = **画面上の行番号**（0..29）。行 i の「その行にあるバー」の配置を、時刻に沿ったキーフレームで定義する（LR2 の流儀でイントロアニメも行ごとに書ける）。
- **DST の timer 欄は無視され、常に timer 0（シーン開始）の経過で評価される。** op1..op3 も評価されない。
- OFF = その行が選択行でないとき、ON = その行が選択行（`listSelectedBarFromScreenTop`）のとき。
- 行 i が描画対象になる条件: `OFF[i−1]` と `OFF[i]` の両方が定義済み（i=1..29）。**行 0 は単独では描かれず、行 1 のスクロール補間先としてだけ使われる**。WMIX は 0..20 を定義しているので描画されるのは行 1..20。行 0 と行 20 は画面外（y=−64, y=736）に置かれ、スクロール時の出入り用。
- WMIX では行 index が大きいほど画面下（y が大きい）。カーソル行 10 は y=336。
- WMIX は全行に ON も定義しているが、`#BAR_AVAILABLE,10,10` のため選択行は常に 10。**実際に効くのは ON[10] だけ**（ON[10] は OFF[10] と同一）。

### 2.4 `#BAR_CENTER,n`
- 選択（カーソル）行の行番号。未指定時 0。シーン開始・フォルダ移動時に選択行はこの値に戻る。WMIX=10、LR2 標準=11。

### 2.5 `#BAR_AVAILABLE,from,to`
- マウスクリックで「スクロールせずに直接その行を選択行にできる」行範囲（両端含む）。範囲外の行をクリックするとリストがスクロールする（§3.6）。未指定時 0,0。WMIX=10,10（実質クリック選択なし）、LR2 標準=6,14。

### 2.6 `#SRC_BAR_TITLE,index,font,st,align` / `#DST_BAR_TITLE,index,...`
- SRC は**テキスト型**: csv[2]=フォント番号、csv[3]=st（バーでは未使用）、csv[4]=align（0=左, 1=中央, 2=右）。
- index 0 = 通常の曲名、index 1 = **新曲**（追加日時が `titleflash` 時間以内、かつ種別 4=ライバルフォルダ以外）。2..4 は未使用。
- 表示文字列 = その要素の fulltitle（タイトル + 半角スペース + サブタイトル）。設定 `disablesubtitle` が真ならタイトルのみ。
- DST の x,y は**バー本体の現在位置（補間後）からの相対**。DST 自体の timer・時間評価・α は通常どおり（バー本体とは独立）。WMIX: TITLE[0] は timer 0 で 0→166ms フェードイン、TITLE[1] は 0..2000ms ループで色を変える（新曲の光り）。
- フォント番号は `#LR2FONT`（画像フォント）と `#FONT`（TTF）で同じ番号空間を共有。その番号の画像フォントが有効（サイズ>0）なら画像フォント、なければ TTF。テキストの縦は DST h（=サイズ）にスケール、横は DST w を超えると横方向に圧縮。

### 2.7 `#SRC_BAR_FLASH` / `#DST_BAR_FLASH`
- 共通 SRC / 共通 DST（index 無視）。
- 選択行が描画されるときだけ、**選択行 ON[選択行] の現在位置（スクロール補間しない）**を原点として描く。DST は相対座標、timer は DST の timer 欄に従う。リストがスクロールしてもフラッシュは選択行に留まる。

### 2.8 `#SRC_BAR_LEVEL,index,gr,x,y,w,h,div_x,div_y,cycle,timer,(未使用),align,keta` / `#DST_BAR_LEVEL`
- SRC は**数値型**（op2=csv[12]=align, op3=csv[13]=桁数）。数値の描き方は §2.15。
- DST はバー本体位置からの相対。
- index の意味（LR2 標準スキンのコメントで確認）:

| index | 意味 |
|---|---|
| 0 | 難易度未定義（#DIFFICULTY なし）／難易度フィルタ無効時 |
| 1 | BEGINNER |
| 2 | NORMAL |
| 3 | HYPER |
| 4 | ANOTHER |
| 5 | INSANE（および exlevel 表示時） |
| 6 | IR ランキング表示中（値 = 順位） |
| 7..10 | 未使用 |

- 描画するのは種別 0 または 5（曲）で keymode > 0 のときだけ。選択ロジック（上から順に最初に当てはまるもの）:
  1. IR ランキング表示中 → [6]、値 = level（= 順位）
  2. 難易度フィルタ無効設定 (`disabledifficultyfilter`) 中 → exlevel>0 かつカスタムフォルダ設定のビット 0x80 が立っていれば [5] に exlevel、そうでなければ [0] に level
  3. 現在のリストが exlevel 系クエリで作られた（`isExLevel`）→ [5] に exlevel
  4. difficulty ≥ 0 → [difficulty] に level
  5. それ以外 → [0] に level

### 2.9 `#SRC_BAR_LAMP` / `#SRC_BAR_MY_LAMP` / `#SRC_BAR_RIVAL_LAMP`（+ 各 DST）
- 共通 SRC。DST はバー本体位置からの相対。
- index = **クリアランプ値**: 0=NO PLAY, 1=FAILED, 2=EASY, 3=CLEAR(NORMAL), 4=HARD, 5=FULL COMBO（WMIX は 1..5 を定義、0 は未定義＝何も出ない）。
- 使うランプ値は「プレイモード別ベスト」:
  - バトル=D-BATTLE → `clear_db`、SP-TO-DP → `clear_sd`、EXTRA モード → `clear_ex`、それ以外 → `clear`
  - フォルダにもランプが付く（設定 `folderlamp` 有効時、中身の曲の最小ランプが入る）。
- どれを描くか:
  - ライバル記録が無い（ライバル EX スコア < 1）または IR ランキング表示中 → `BAR_LAMP[値]`。ランキング表示中はランキング行のクリア値。
  - ライバル記録がある（ライバル EX ≥ 1）かつランキング非表示 → `BAR_MY_LAMP[自分の値]` と `BAR_RIVAL_LAMP[ライバルの値]` の 2 つ。ライバル値は通常モードのときだけライバルの `clear`、D-BATTLE/SP-TO-DP/EXTRA では 0。

### 2.10 `#SRC_BAR_RIVAL` / `#DST_BAR_RIVAL`（勝敗マーク）
- ライバル記録がある（ライバル EX ≥ 1）かつランキング非表示のときに描く。index:
  - 0 = 自分の EX > ライバル（WIN）
  - 1 = 自分 < ライバル（LOSE）
  - 2 = 同点（DRAW）
  - 3 = 自分が未プレイ（自分の EX = 0）
- WMIX は 0..2 を定義（3 は未定義）。

### 2.11 `#SRC_BAR_RANK` / `#DST_BAR_RANK` [-]
- IR ランキング表示中、曲バー（種別 0/5）のランキング行の rank が 1..9 のとき `BAR_RANK[rank]`。
- rank = `EX * 9 / (notes*2)`（整数除算）を最大 8 に丸め、EX>0 で 2 未満なら 1。8=AAA, 7=AA, 6=A, 5=B, 4=C, 3=D, 2=E, 1=F。

### 2.12 `#SRC_ONMOUSE` / `#DST_ONMOUSE`
- SRC: 共通 SRC + op1=csv[11]=**panel**, op2=csv[12]=判定 x オフセット, op3=csv[13]=判定 y オフセット, op4=csv[14]=判定 w, op5=csv[15]=判定 h。
- 判定矩形 = (DST の現在 x + op2, DST の現在 y + op3, 幅 op4, 高さ op5)。マウスがこの中にあり、かつ `panel==0`（常時）または `panel == 現在開いているパネル番号` のときだけ、DST 通常位置・通常サイズで画像を描く。
  - panel=-1 なら「どのパネルも開いていないとき」だけ（現在パネル値が -1 のため）。
- DST の op1..op3 も評価する。readme 表示中は ONMOUSE は一切描かない。
- WMIX: panel 0 が 9 個、1 が 40 個、2..6 が少数。

### 2.13 `#SRC_README,index,font,st,align,行間` / `#DST_README,index,...`
- SRC はテキスト型（csv[2]=フォント, csv[3]=st 未使用, csv[4]=align）＋ **csv[5]=行の高さ(px)**。WMIX は font 3, 行間 18。
- テキストファイルの各行 i を、`(DST.x + 横スクロール量, DST.y + 行間*i + 縦スクロール量)` に描く。index 0 と 1 の両方が毎行描画される（行間はそれぞれの SRC の値）。画面外の行は省略。
- 典型的な使い分け（WMIX）: [0] は timer 15（readme 開）で 0→800ms フェードイン、[1] は timer 16（readme 閉）で 255→0 フェードアウト。閉じても行データは残るので [1] が消えていく演出になる。
- readme の開き方・操作は §5.4。

### 2.14 `#SRC_MOUSECURSOR` / `#DST_MOUSECURSOR`
- 共通 SRC/DST。DST 座標はマウス座標からの相対。
- 最後にマウスが動いてから 10 秒未満 → 通常描画。10〜10.5 秒 → α を 255→0 に線形フェード（ブレンドは α 固定）。それ以降 → 非表示。
- WMIX は timer 0 の 800→1000ms でフェードイン。

### 2.15 数値の描き方（`#SRC_NUMBER` と `#SRC_BAR_LEVEL` 共通）
- 共通 SRC + op1=csv[11]=数値 ID（BAR_LEVEL では未使用）, op2=csv[12]=align, op3=csv[13]=桁数。
- フレーム数が 10 の倍数 / 11 の倍数 / 24 の倍数のいずれかでないと描かない。桁数 ≤ 0、align が 0..2 以外も描かない。cycle>0 なら「10/11/24 枚のセット」を時間で切り替える。
- 10 枚: 数字のみ。11 枚: 10 番目 = 空白桁用。24 枚: 0..11 が正（10=空白, 11=正符号）、12..23 が負（23=負符号）で先頭に符号を描く。
- 負の値は 24 枚セット以外では描かない（ID が未定義なら -1 が返る → 非表示になる）。
- align 0 = 右詰め（下位 keta 桁、桁あふれは上位を切る）、1 = 左詰め、2 = 中央（空き桁数×w/2 だけ右へずらす）。左詰め/中央では後ろの空き桁を空白フレームとして描く（11 枚セットのとき）。

### 2.16 `#HELPFILE,path`
- 出現順に 0..9 番として最大 10 個登録。ボタン 200+n（§6.7）で n 番を readme 表示する。WMIX は 7 個（main, playoption, systemoption, score, tageditor, effect, playerstatus）。パネル 0..6 のヘルプボタンに対応。
- テキストは CP932 として読む。ヘルプファイル表示時は幅・高さに `#TEXTMERGIN` の値（既定 10,10）を足す。

### 2.17 `#RELOADBANNER`
- 指定時のみ、選曲中に**カーソル曲が変わるたびにバナーを非同期で読み込み**、gr 102（BANNER）に差し替える。読み込み完了時にカーソル曲がもう違えば破棄。読めなかった曲は「バナー無し」扱いになる（op 192/193 に反映）。
- OpenLR2 は未指定ならバナーを選曲画面で読まないが、原典 LR2 では未指定の WMIX でも選曲画面にバナーが出る（ユーザーの確認、2026-10-20）。BMjoy は指定にかかわらず読む。
- STAGEFILE（gr 100）・BACKBMP（101）は選曲画面では読まれない（決定画面で読む）。

### 2.18 選曲画面で意味のあるその他ヘッダ
- `#STARTINPUT,ms` … 1 番目の値。シーン開始からこの時間を超えると入力受付開始（timer 1 起動）。WMIX=600。2,3 番目はリザルト用。
- `#FADEOUT,ms` … キーコンフィグ/スキンセレクトへ移るときだけ使われる（timer 2 起動後この時間で遷移）。**曲決定時は選曲画面のフェードアウトは無く即座に決定画面へ**。WMIX=500。
- `#TEXTMERGIN,x,y` … ヘルプ表示の余白。

## 3. 曲リストのレイアウトとアニメーション

### 3.1 状態量（すべて 1 曲 = 1000 の固定小数）
| 名前 | 意味 |
|---|---|
| N | リスト要素数 |
| `listTopbar` | 現在のスクロール位置（補間後, 無限に増減しうる） |
| `listCalculatedBar` (LCB) | listTopbar を [0, N*1000) に正規化したもの |
| `oldBar`, `nowBar` | スクロール補間の始点・終点 |
| `barMoveStartTime`, `barMoveEndTime` | 補間の開始・終了時刻（絶対 ms） |
| `scrollDirection` | 1=上（前の曲へ）, 2=下（次の曲へ） |
| `listSelectedBarFromScreenTop` (sel) | 選択行の行番号（通常 BAR_CENTER） |
| C | BAR_CENTER |
| `cur_song` | カーソル曲の index |

毎フレーム（リスト読込中でなければ）:
```
listTopbar = lerp(oldBar, nowBar, barMoveStartTime, barMoveEndTime, now)   // 線形、範囲外は端の値、int 化
LCB = listTopbar を N*1000 で正規化
cur_song = (sel - C + floor(LCB/1000) + (LCB%1000 != 0 && scrollDirection==2 ? 1 : 0) + N*30) mod N
```
- つまり**移動開始の瞬間にカーソル曲は次（前）の曲に切り替わる**（下方向は端数があれば +1、上方向は floor で即座に前の曲）。

### 3.2 各行に出す要素
- 行 i（1..29、§2.3 の条件を満たす行）に出す要素 index:
  `bar = (floor(LCB/1000) − C + i) mod N`（負なら N を足す）
- リストは**循環**。N が行数より少なければ同じ曲が複数行に出る。

### 3.3 行間補間
- 行 i の基準配置 A = 行 i が選択行なら ON[i]、そうでなければ OFF[i]（timer 0 経過で評価）。
- 行 i−1 の配置 B = 行 i−1 が選択行なら ON[i−1]、そうでなければ OFF[i−1]。
- frac = LCB % 1000。frac=0 なら A、そうでなければ A と B を frac/1000 で線形補間（x,y,w,h,a,r,g,b,angle,sortID。blend/filter/center は A のもの）。
  - frac が 0→1000 に進むとき、要素は行 i から行 i−1 へ（WMIX では画面上方向へ）動く。
- A または B のどちらかがその時刻で非表示（先頭キーフレーム前など）なら、その行は描かない。
- 曲バー本体 = `SRC_BAR_BODY[種別]` をこの補間位置に描く。続いて（選択行なら FLASH）、TITLE、LEVEL、LAMP 類、RIVAL/RANK を**補間位置を原点とする相対座標**で描く（これらは各自の DST 行の sortID で並ぶので、スキン上で後に書けばバーより手前）。

### 3.4 IR ランキング切替時のスライド
- ランキングを開く/閉じる遷移中、全行の x に加算: 閉じ始め（timer 175）は 0→+300px、開き始め（timer 176）は +300→0px、どちらも 120ms 線形。FLASH の原点にも同じ加算が乗る。§5.6 参照。

### 3.5 キー・ホイールによるスクロール
- 1 段移動の操作（§4.2）が来たとき:
  ```
  nowBar ±= 1000 ; oldBar = listTopbar（現在位置）; barMoveStartTime = now
  barMoveEndTime = now + speedfirst（押した瞬間） / now + speednext（押しっぱなしのリピート）
  ```
  - 「押した瞬間」の移動は前の移動が終わっている（now > barMoveEndTime）ときだけ。
  - 「押しっぱなし」のリピートは now > barMoveEndTime − 20 のとき。
  - 既定 speedfirst=300, speednext=70（config.xml の select/speedfirst, speednext。0 以下なら既定値）。
  - 結果として、押下 → 約 280ms 後から約 50ms ごとに 1 段ずつ目標が進み、各移動は 70ms かけて補間される（補間が終わる前に次が始まる）。[?] OpenLR2 の式どおり。
- マウスホイール: ホイール量 w（上=正）に対し `nowBar −= w*1000`、補間時間 200ms、前の移動の完了は待たない。上回しで前の曲、scrollDirection も上=1/下=2。
- 曲リスト位置スライダー（スライダー種別 1）については §6.6。

### 3.6 マウスによる曲バー操作
- 判定は各行の **OFF[i] 配置（timer 0 評価）の矩形**で行う（ON ではなく OFF）。テキスト入力欄の上にマウスがあるときは無効。
- 左ボタンを**押している間（状態 2）**、マウス下の行 i について:
  - i < from（BAR_AVAILABLE）: スクロール停止中（nowBar == listTopbar）なら `nowBar += (i − from) * 2000`、200ms 補間
  - from ≤ i ≤ to: `sel = i`（選択行がその行になり、カーソル曲が変わる。スクロールはしない）
  - i > to: 停止中なら `nowBar += (i − to) * 2000`、200ms 補間
  - [?] 行数差 × 2000（＝2 曲分/行）は書き起こしどおり。1000 の誤記の可能性あり。原典での確認を推奨。
- **選択行の ON[sel] 矩形の上で左ボタンを押した瞬間（状態 1）** → 決定（§4.3）。つまり範囲内の別の行は「1 回目のクリックで選択、2 回目で決定」。
- 右ボタンを離した瞬間（状態 3）の扱いは §4.4。

### 3.7 リストの再構築時の位置決め
- フォルダを開いた/検索した直後: 先頭要素が選択行に来るよう `listTopbar = (C − sel)*1000`（sel は保持）。
- フォルダを閉じた直後: 直前に開いていたフォルダ要素が選択行に来る位置。
- フィルタ（難易度/鍵盤数/ソート）変更でリストを作り直したとき: 同じファイル → 同じフォルダかつ同じ keymode の要素… の順で元の曲を探し、`listTopbar = その index*1000 + (C − sel)*1000`。
- いずれも補間無し（oldBar = nowBar = listTopbar, start=end=now）、timer 11 を起動、カーソル曲情報を更新。

## 4. 入力と操作

### 4.1 リスト入力を受け付ける前提条件
次をすべて満たすときだけ §4.2〜4.5 の操作が有効:
- シーン開始からの経過 > `#STARTINPUT`
- readme（テキストビューア）非表示
- テキスト入力中でない
- このフレームにスキンボタンがクリックされていない
- リスト読込中でない
- テキスト入力確定（timer 4）から 0..100ms の間でない
- F2 マニアックオプション非表示、F3 を押していない
- さらに §4.3〜4.5 の決定・鍵盤 6・難易度切替・曲バークリックは「スライダーをドラッグ中でない」ときだけ判定される（スクロール・ホイール・フォルダを閉じる・右クリックはドラッグ中でも有効）。
- 判定は if-else の連鎖で、1 フレームに 1 種類だけ実行される。優先順: スキンボタンによる画面遷移/オート/リプレイ → 鍵盤 6 → 鍵盤 6 ホールド継続 → 難易度切替 → （決定入力が無ければ）曲バーのマウス処理 → （決定入力があれば）決定。

### 4.2 ボタン番号と標準キー割当
コントローラーのボタン番号（keyconfig）: 1..9 = 鍵盤 1..9、10/11 = スクラッチ（2 方向）、12 = START、13 = SELECT。1P/2P 両側とも同じ扱い（特記以外）。

| 操作 | キーボード | コントローラー（通常） | 備考 |
|---|---|---|---|
| 前の曲（上） | ↑ | スクラッチ(10) | `buttonselect` 有効時は鍵盤 1 も |
| 次の曲（下） | ↓ | スクラッチ(11) | `buttonselect` 有効時は鍵盤 3 も |
| 決定／フォルダを開く | Enter, → (フォルダ選択時) | 鍵盤 1,3,5,7 | `buttonselect` 有効時は 5,7 のみ。パネル 1 表示中は鍵盤では決定しない |
| フォルダを閉じる | ← | 鍵盤 2 | パネル 1 表示中は無効。右クリックでも可 |
| 難易度フィルタ切替 | →（曲選択時） | SELECT | パネル 1 表示中は無効。keymode ≥ 5 の曲のみ |
| オートプレイ／リプレイ | （F: マニュアル記載） | 鍵盤 6 | §4.5 |
| IR ランキング表示 | （d: マニュアル記載） | 鍵盤 4 を押し続ける | §5.6 |
| プレイオプション（パネル 1） | Space | START（または鍵盤 9） | §5.2 |
| ゲーム終了 | Esc | | §4.6 |

- キーボードの z,x,c,v,s,d,f 等はキーコンフィグで鍵盤に割り当てられているもの（マニュアル: z/x/c/v=決定、s=閉じる、d=ランキング、f=オート）。
- 設定 `control`（PMS 用操作、`keyconfig_p.xml` を使う）が真のときは割当が変わる: 鍵盤 4=上, 6=下, 5/7=決定, 3=閉じる, 1=オートプレイ, 2 または 8=難易度切替。→ による難易度切替は無効。[?] 原典 LR2 にこの設定があるかは未確認（config.xml の select/control として読まれる）。
- 鍵盤 1..9 の押下/離しで timer 100+k / 120+k（1P）、110+k / 130+k（2P）が更新される（k=0..9。WMIX は 101..107, 111..117 を使用）。テキスト入力中は鍵盤入力は全部 0 扱い。

### 4.3 決定時の分岐（カーソル要素の種別）
1 フレームに 1 つだけ判定（if-else 連鎖）。決定入力が来たら:
- 種別 9（ランダムコース）→ ランダムコースを生成してプレイ。
- 種別 7（コース作成）→ コース作成モードへ（timer 17 起動、パネル開音）。
- keymode ≤ 0 かつコースでない（= フォルダ類）→ フォルダを開く。リスト読込（timer 170 起動 → 完了で 170 解除・171 起動）、完了時にフォルダ開音（`#FOLDER_OPEN`）。開いたフォルダが「上限 1 曲」のランダム選曲フォルダならそのまま決定。
- 再生不可のコース → 何もしない。
- コース作成中 → 曲をコースに追加（最大 5、keymode が揃っている必要）。
- それ以外（曲・プレイ可能コース）→ **即座に決定画面へ**（通常プレイ）。

### 4.4 フォルダを閉じる・右クリック
- ←／鍵盤 2（パネル 1 非表示、階層 > 0）→ 1 階層戻る。完了時フォルダ閉音（`#FOLDER_CLOSE`）。
- 右ボタンを離した瞬間:
  1. マウスが曲バー上でなく、何かパネルが開いている → そのパネルを閉じる（パネル閉音）
  2. 曲バー上でなく、コース作成中で 1 曲以上入っている → 最後の曲を取り除く
  3. 上記以外で（曲バー上、またはコース作成中でない）階層 > 0 → 1 階層戻る

### 4.5 鍵盤 6（オートプレイ／リプレイ）
- パネル 1 非表示で鍵盤 6 を押した瞬間、カーソルが曲（keymode > 0）なら:
  - リプレイがあり、ランキング非表示 → ホールド開始（timer 172 起動）
  - なければ即オートプレイで決定。
- ホールド中: 離したら（2000ms 未満）オートプレイ、2000ms を超えて押し続けたらリプレイ再生で決定。[?] ログ文言は「1 秒」だがコードは 2000ms。
- ランダムコースならランダムコースをオートで開始。

### 4.6 その他のキー
- Esc: timer 4 が 0..100ms でない、テキスト入力中でない、#STARTINPUT 経過後 → **LR2 自体を終了**。
- F1 ヘルプ表示、F2 マニアックオプション、F3 レベル/難易度変更、F4 ウインドウ切替、F5 IR ページ、F6 SS、F7 FPS、F8 フォルダ再読込（いずれも LR2 本体機能。スキンとの関係は薄いので詳細省略）。

### 4.7 難易度フィルタ切替（→ / SELECT）の詳細
- 対象は keymode ≥ 5 の曲のみ。
- `disabledifficultyfilter` 有効 → 代わりに鍵盤数フィルタ（MODE）を 1 つ進める。
- `difficultychangetype` 有効 → 難易度フィルタを 0..5 で 1 つ進める（ループ）。
- 既定（どちらも無効）→ カーソル曲を基準に「同じ難易度の別譜面が残っていればそれ」→「より上の存在する難易度」→ どれも無ければ ALL（`ignoredifficultyall` なら最低難易度）へ。
- リスト再構築後、`#DIFFICULTY` 音があればそれ、なければフォルダ開音。
- 難易度値: 0=ALL, 1=BEGINNER(EASY), 2=NORMAL(STANDARD), 3=HYPER(HARD), 4=ANOTHER(EXPERT), 5=INSANE(ULTIMATE)（括弧内は optionstr.csv の表示名）。

### 4.8 効果音（サウンドセット名）
| 契機 | サウンド |
|---|---|
| カーソル曲が変わった（リスト読込直後を除く、timer 1 起動後） | `#SCRATCH` |
| フォルダを開く/検索結果 | `#FOLDER_OPEN` |
| フォルダを閉じる | `#FOLDER_CLOSE` |
| パネルを開く / 閉じる | `#PANEL_OPEN` / `#PANEL_CLOSE` |
| オプション変更、readme 表示など | `#OPTION_CHANGE` |
| 難易度フィルタ変更 | `#DIFFICULTY`（無ければ `#FOLDER_OPEN`） |
| BGM | `#SELECT`（EXTRA モード時は `#EXSELECT` があればそれ） |

### 5.4 テキストビューア（readme / ヘルプ）
- 開く: ボタン 17（曲フォルダ内の .txt 全部を連結表示。複数なら各ファイル先頭に「n/総数 ファイル名」行）、ボタン 200+n（#HELPFILE の n 番）。開けたら timer 16 解除・15 起動・`#OPTION_CHANGE`。
- 表示中は選曲操作・ボタン・スライダー・テキスト入力・ONMOUSE がすべて止まる。
- スクロール: ホイールで行間×量、↑ 押しっぱなしで +0.6px/ms、↓ で −1.2px/ms（下方向が速い）。マウス左押しっぱなしで画面端 200px（左右）/150px（上下）付近にいると同様の速度で横/縦スクロール。スクロール量はテキスト全体が画面内に収まる範囲（0 以下、−(全体 − 画面) 以上）に制限。
- 閉じる: 右ボタン離し、F2、鍵盤 1..7 のいずれか（1P/2P）押下、Enter。timer 15 解除・16 起動。

### 5.5 テキスト入力（検索・タグ編集）
- `#SRC_TEXT,_,font,st,align,edit,panel`: edit=1 の項目は、パネル条件を満たしていればクリック（左ボタン離し）で入力開始。入力中は timer 等はそのまま、確定/取消で timer 4 起動。
- st=30 が検索欄（WMIX は panel -1）。数値のみなら「LEVEL n」検索、`a-b` は範囲、50 以上は BPM 検索、`/` で始まるとコマンド。結果は「語 (n HITS)」として文字列 30 に入る。
- st=20,21,23..29 はタグエディター（パネル 4）の各項目、st=170 はコース名。

### 5.6 IR ランキング表示（鍵盤 4 長押し）
- 条件: スクロール停止中（timer 10 未起動）、IR 取得完了状態、パネル 1 非表示、スクラッチ/↑↓を触っていない。
- 鍵盤 4 を押し続ける → timer 175 起動、120ms 後にリストをランキング表（順位=level、名前=タイトル、ランキング行のスコア/ランプ）に差し替え、timer 175 解除・176 起動、パネル開音。文字列 1 = カーソル行のプレイヤー名。
- 鍵盤 4 を離す → 同様に 175 → 120ms 後に元のリストへ戻し、176、パネル閉音。
- この間 op 620/621 が切り替わる。

## 7. OpenLR2 拡張（オリジナル LR2 に無いもの）
BMjoy で LR2 互換を目指す場合は入れない（入れる場合は別フラグ）。
- `#INFORMATION` のサイズ指定、`#RESOLUTION`
- 文字列 300/301/302、数値 295/418/421/422、スライダー 27/28、ボタン 331/400/401
- ボタン 55 の値 5（MAINBPM）、ボタン 80 の値 2（BORDERLESS）
- op 270 のリフト部分、274、275、626
- BARGRAPH 48/49/58/59、数値 201/210..218 のプレイ中 FAST/SLOW 化
- Custom IR（ランキングのキャッシュ復元、取り込みスコア myIRbest。これがある曲はランプ・数値の元データが取り込みスコアになる）
- 原典 LR2 にあると history.txt で確認できたもの（拡張ではない）: 曲プレビュー（FMODEx 時）、難易度フィルタ無効オプション、`#DIFFICULTY` 音、パネル開閉状態のシーン越し保持、readme 表示、スコアパネルの IR ボタン。

## 8. 未確定事項・要確認
1. **マウスクリックでの範囲外スクロール量**: `(行差) × 2000`（2 曲/行）。1000 の可能性あり。
2. **timer 10** の正確な意味（スクロール中に毎フレーム再起動される式）。「スクロール中なら起動中」として扱うのが安全。
3. **文字列 61（SORT 名）** が鍵盤数フィルタ値で引かれている件。本来はソート値と思われる。
4. **ボタン 12（ソート）** のループ範囲 0..4（RANK=5 に届かない）。
5. **パネル 1 を START 押下で閉じたときに閉音が鳴らない**、HS-FIX 逆方向で非バトル時に音が鳴らない — 書き起こしどおりかは不明。
6. **鍵盤 2 長押しの EXTRA モード切替**、`control`（PMS 操作）設定が原典 LR2 にあるか。
7. **リプレイ長押し時間**: コード 2000ms、ログ文言「1 秒」。
8. **`#RELOADBANNER` 未指定時のバナー**: OpenLR2 では選曲中に一切読まない。原典の挙動は未確認。
9. **WMIX のパネル 2 内のボタン 170..191 / 220..224, スライダー 7, 文字列 50/51/100..114**: OpenLR2 ではスキンセレクト画面の ID。選曲画面内でスキン種別ボタンを押すと、スキンプレビュー生成まで走る実装になっている。原典 LR2 で選曲画面のシステムパネルにスキン選択機能があるのか（WMIX が想定しているのか）を要確認。BMjoy では当面「表示のみ・クリック無効」で良いと思われる。
10. **op 570/571/572** は書き起こしで break 抜け（次の case に落ちる）。572 は「作成中でない」で真、それ以外は 700 系条件になる。WMIX は 572 を使用。
11. **DST loop > 最終 time** のとき t=0 固定になる件（一般的な LR2 スキン仕様と合っているか）。
12. WMIX の `#DST_BAR_BODY_OFF,1,466,...,a=25500` のように a > 255 の値の扱い（255 に丸めると推定）。
13. folderType と op 1 の対応で、種別 5（ライバル用の曲）は op 2/5 側、種別 7/9 は op 4 側、種別 8 は op 3/5 側。種別 1..4,6 がフォルダ（op 1）。この分類は OpenLR2 の式どおりで、原典資料での裏付けは WMIX/LR2 標準スキンのコメントのみ。
